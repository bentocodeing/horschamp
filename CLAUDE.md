# Horschamp

Unofficial, open-source (MIT) Tauri 2 desktop client for the Higgsfield API. React 19 + TypeScript frontend in `src/`, Rust backend in `src-tauri/`. See `README.md` for features and setup.

## Commands

- `pnpm tauri dev`: run the full app (Rust + webview).
- `pnpm dev`: frontend only on port 1430, with a fake backend (`src/dev/mock.ts`). Use this to check UI changes in a browser.
- `pnpm check`: lint + format check + type check (Vite+ / oxlint / oxfmt). Run before saying a change is done.
- `pnpm fmt`: format. `pnpm test`: Vitest (`src/**/*.test.ts`). `pnpm test:rust`: cargo tests.
- Use `pnpm` and `vp`, never `npm` or `npx`.

## Architecture

- All Higgsfield and Anthropic API calls happen in Rust (`src-tauri/src/hf.rs`, `director.rs`), exposed as Tauri commands in `commands.rs`.
- The frontend calls Rust only through the typed client in `src/lib/api.ts`. Global state lives in `src/store.ts` (zustand).
- Screens are in `src/screens/`, feature components in `src/components/<feature>/`, shadcn/ui primitives in `src/ui/`.
- Jobs: quote → confirm → submit → poll → download, in `src-tauri/src/jobs.rs`. Storage is SQLite (`db.rs`).

## Rules that must not break

- API keys stay in the OS keychain (`secrets.rs`). They never reach the webview, logs, error messages or `Debug` output. The frontend only sees a masked hint.
- Do not add Tauri fs, http or shell plugins to the webview, and do not loosen the CSP in `tauri.conf.json`.
- Spend safety is enforced in Rust: a job is refused unless the user confirmed a price at least as high as the current estimate. Never move this check to the UI only.
- When adding a Tauri command, also add it to `src/lib/api.ts` and to the mock in `src/dev/mock.ts`, or `pnpm dev` breaks.

- Brand: never present the app as official or endorsed by Higgsfield. Use "Higgsfield" only to name the service ("for the Higgsfield API"), never in the product name, and do not use their logo, imagery or exact brand colors.
- Bundle id is `app.horschamp.desktop`. Data from the old id `app.studio.higgsfield-client` is migrated in `lib.rs` and `secrets.rs`; keep that code until old builds are gone.

## Conventions

- Write code, comments, docs and commit messages in US English.
- Style UI with the tokens in `src/styles/tokens.css` (see `docs/DESIGN_SYSTEM.md`). Avoid new raw hex colors in components.
- Import from `src/` with the `@/` alias.
- Commit messages: `area: short lowercase summary` (e.g. `ui: ...`, `rust: ...`, `docs: ...`).

## Gotchas

- `models.json` is generated by `pnpm refresh-models`. Do not hand-edit or reformat it; it is excluded from oxfmt on purpose.
- The dev server port is fixed at 1430 (`strictPort`). If it is busy, free it instead of changing the port.
